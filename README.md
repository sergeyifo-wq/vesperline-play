# Vesperline

Play at https://sergeyifo-wq.github.io/vesperline-play/

A single-player corporate strategy game set in Night City, 2077. This repository holds only the built site and is replaced on every publish.

Unofficial fan work. Night City and the 2077 corporations are used as setting; the company, prose, and pictures are original. The game runs in the browser and sends nothing to a server.
